# Лабораторна робота 1: Версії Python, віртуальні середовища та структури даних

Короткий опис виконаних завдань у межах лабораторної роботи.

## Структура репозиторію
* `diff_py2.py` / `diff_py3.py` — демонстрація відмінностей між Python 2 і Python 3.
* `version_test.py` — тестовий скрипт для перевірки поведінки в різних версіях Python.
* `version_test_rich.py` — перевірка роботи з бібліотекою `rich` у середовищі.
* `task4.py` — обробка студентських оцінок з файлів (списки, словники, цикли).
* `student_marks/` — папка з вхідними файлами даних (`math.txt`, `statistics.txt`, `physics.txt`, `student_names.txt`).

### Списки, словники та цикли

#### Завдання
1. **Зчитати файли:**
   * За допомогою `os.listdir()` перевірте наявність та відкрийте для зчитування файли: `math.txt`, `statistics.txt`, `physics.txt` та `student_names.txt`.
2. **Обробка даних:**
   * Зчитайте оцінки у списки цілих чисел для кожного предмета та сформуйте список імен студентів.
   * Створіть загальний словник, де ключ — ім'я студента, а значення — вкладений словник з предметами та їх оцінками (`{student: {subject: grade}}`).
3. **Виведіть результати:**
   * **Статистика по студентах:** ім'я та середня оцінка по всіх трьох предметах.
     > *Приклад виводу:* `студент: … , середня оцінка: …`
   * **Топ-3 студенти:** троє учнів із найвищими середніми балами.
     > *Приклад виводу:* `Студент 1`, `Студент 2`, `Студент 3`
   * **Загальна статистика:** загальна кількість студентів, середні, мінімальні та максимальні оцінки по кожному предмету.
     > *Приклад виводу:* 
     > `Загальна кількість студентів: …`
     > `предмет: … , середня оцінка … , min оцінка: … , max оцінка: …`
   * **Лідери предметів:** ім'я студента з найвищим балом для кожного окремого предмета.
     > *Приклад виводу:* `Предмет 1: … | студент: … , оцінка: …`
   * **Студенти з низьким балом:** кількість та список студентів, чия середня оцінка нижче за 50.
     > *Приклад виводу:* 
     > `Кількість студентів з оцінкою нижче 50: …`
     > `Студент 1`, `Студент 2`, `…`
